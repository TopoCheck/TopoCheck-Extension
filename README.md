# TopoCheck

**Understand networks. Spot errors instantly.**

TopoCheck is a Visual Studio Code extension and learning environment for visual network topologies. It is developed to help students understand network configurations, identify errors, and receive clear feedback directly in Visual Studio Code.

## Features

* Visual representation of network topologies
* Creation and management of network devices and connections
* Automatic generation of device configurations
* Validation of network configurations
* Detection of syntax, semantic, and logical errors
* Clear and understandable feedback for configuration errors

TopoCheck is currently under active development as part of a diploma project.

## Requirements

* Visual Studio Code 1.125.0 or later

## Extension Settings

TopoCheck currently does not provide any additional VS Code settings.

## Known Issues

TopoCheck is currently in development. Some planned features and networking technologies are not yet fully implemented.

## Planned Technologies

The project is planned to support networking technologies and protocols such as:

* RIP
* OSPF
* VLAN
* STP
* DHCP
* DNS
* NTP
* ACL

## Project

TopoCheck is developed as a diploma project at **HTL Wien 3 Rennweg** in Vienna, Austria.

The project focuses on creating a visual and educational environment for learning computer networking and understanding configuration errors.
